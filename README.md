# 🌦 Project: Weather API

A simple and clean weather lookup application that allows users to search for current weather conditions in any city around the world using the [WeatherAPI](https://www.weatherapi.com/).

### Project Goals

- Learn how to consume a REST API using JavaScript `fetch()`
- DOM manipulation to display dynamic data
- Handle user input validation and error states
- Build a responsive UI with real-time weather data

### Features

- Search weather by city and country
- Display current temperature (°F)
- Show weather condition with icon
- Wind speed, humidity, visibility, and "feels like" temperature
- Input validation (prevents empty searches)
- Error handling for invalid cities

## Technologies used

- HTML5
- CSS3
- JavaScript
- API
  [WeatherAPI](https://www.weatherapi.com/) 

## What I learned

- How to work with REST APIs and JSON responses
- Dynamic DOM manipulation with getElementById and querySelector
- Building user-friendly error messages
- Structuring a front-end project with separate CSS/JS files
