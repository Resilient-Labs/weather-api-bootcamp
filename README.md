# 🌦 Weather API

### Simple weather web application that displays the current weather for any location by entering a city, state, and country. 

### Features 
## Location Search bar: Allows user to input a city, state, and country to retrieve local weather. 

## Temperature Display : Displays the current temperature in Fahrenheit. 

## Current Conditions: Displays the current weather description(sunny, cloudy, rainy, etc.)
