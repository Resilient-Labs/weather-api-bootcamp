# 🌦 Project: Weather API

This is a simple weather application that allows users to enter a city and view weather information for that location. When the user clicks the Get Weather button, the application retrieves weather data from a weather API and displays the city name and temperature.

This project was created to practice working with APIs, JavaScript fetch(), user input, and displaying API data in the DOM.

🛠️ Tech Stack

HTML — Creates the structure of the application, including the input, button, and weather display.

CSS — Adds styling and a background image to the application.

JavaScript — Handles user input, makes the API request, and displays the returned weather data on the page.

Weather API — Provides the weather and forecast data used by the application.

✨ Features

Search for weather by city

Displays the searched city name

Displays the forecasted maximum temperature

Retrieves live weather data using an API
