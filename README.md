Weather API

How It's Made:

Tech used: HTML, CSS, JavaScript, Framework of choice

Using the open weather map api users can input their city of choice and get back the temperature at their location! I grabbed the input from the user and sent it overr to the weather API, inserting it in the URL city search query.
