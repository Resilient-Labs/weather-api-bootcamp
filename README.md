# 🌤️ The Weather App
A simple weather application that allows users to search for a city and retrieve current temperatures in both Fahrenheit and Celsius. Built using JavaScript and the WeatherAPI to showcase API integration, asynchronous data fetching, and DOM manipulation.

## Features
- **City Search:** Enter a city to retrieve current weather information.
- **Live Weather Data:** Fetch current temperatures using WeatherAPI.
- **Temperature Conversion:** Display temperatures in Fahrenheit and Celsius.
- **Dynamic Updates:** Display weather results directly on the page without refreshing.

## Tech Stack 
- HTML5
- CSS3
- JavaScript
- WeatherAPI

## Getting Started
1. Clone the repository:
```bash
git clone https://github.com/CarlyJovon/weather-app.git
```
2. Navigate into the project folder:
```bash
cd weather-app
```
3. Add your WeatherAPI key to the JavaScript configuration.
4. Open `index.html` in your browser or use VS Code Live Server.
