# Project: Weather API ☁️ ☀️

### Goal: A simple front-end app that displays weather data returned from an API

## Result: A simple weather app ☁️

* An app that calls a weather API.
* A user inputs their city.
* The city is used as a query parameter in the API call.
* The API returns weather data for that location.
* The weather data is displayed on the page.

## Future improvements

* Make CSS styling changes
* Add more weather information
* Improve error handling
* Add more ways to search for a location
