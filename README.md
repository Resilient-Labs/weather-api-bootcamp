# 🌤️ 🌈 Find Weather Explorer

Check the temperature anywhere in the world! Enter a city and country to fetch the current weather in **Fahrenheit**, with a smooth animated gradient and interactive UI for extra flair!  

---

## ✨ Features
- 🌍 Enter **city** and **country** to get live weather  
- 🌡️ Displays **temperature in Fahrenheit (°F)**  
- 🎨 **Animated gradient background** for a vibrant look  
- 📱 Fully responsive and simple design  

---

## 🛠️ Built With
- **HTML5** – structure  
- **CSS3** – animations, gradients, responsive design  
- **JavaScript** – fetch OpenWeatherMap API & update content dynamically  

---
