Global Weather App is an application that will return the weather for any location the user searches.

- Responsive display where users can see the temperature at their selected location.

## Installation

1. Clone the repository:

```bash
git clone https://github.com/yourusername/Global-Weather-App.git
````

2. Navigate to the project directory:

```bash
cd Global-Weather-App
```

3. Open Project File

4. Use in browser
   
## Usage

1. Enter information for the city you are looking for
2. Click button to generate temperature
