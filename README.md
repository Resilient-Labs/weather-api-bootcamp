# Project: Weather API
<img width="1920"  alt="image" src="https://github.com/user-attachments/assets/55cfc037-932d-4fa8-bd9c-ed93577e1f23" />

This code provides the front-end logic for a simple weather application that uses the OpenWeatherMap API to retrieve current weather data for a user-specified city. An event listener is attached to a button, triggering the getFetch function when clicked. This function reads the city name from an input field, constructs a fetch request using a hardcoded API key, and sends it to the OpenWeatherMap endpoint. Upon receiving the JSON response, the script performs a calculation to convert the temperature from Kelvin to Fahrenheit and then dynamically updates <h3> and <h4> DOM elements with the current temperature and wind speed, respectively
