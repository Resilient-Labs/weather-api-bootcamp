# Weather App

The Weather App is a simple front-end web application that allows users to enter a city and country to retrieve the current temperature in Fahrenheit. Users can search for different locations and view the temperature based on the weather data returned from an external API.

The application uses a weather API to retrieve real-time weather information based on the user's location search.

## Features
Location Search: Enter a city and country to search for weather information.
Weather Information: Retrieve the current temperature for the selected location.
Temperature in Fahrenheit: Display temperatures in Fahrenheit.
API Integration: Fetch current weather data from an external weather API.
Dynamic Content: Update the displayed temperature based on the user's search.
Interactive Interface: Easily search for weather information in different locations.

## Tech Stack
Frontend: HTML, CSS, JavaScript
API: External Weather API
