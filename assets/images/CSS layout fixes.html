1. place-items:center isn't doing anything here

You have:

place-items works with CSS Grid (and some other layout contexts), but .container isn't display: grid.

If you want it to work, you'd need:

CSS
.container {

}

But based on your current layout, I wouldn't add that yet, because it could change the positioning of all your elements.

2. You have a typo here

CSS
.contain {
    border:px solid pink;
}

px needs a number before it.

For example:

CSS
border: 1px solid pink;

Or if you don't want a border:

CSS
border: none;

3. Your .inline has a negative margin

CSS

    display:flex;
    justify-content:center;
    align-items:center;

}

The margin-top: -30px is literally pulling the element 30px upward.

That's not necessarily wrong, but if you're wondering why your inputs/buttons are sitting strangely, this is one of the reasons.

You have:

CSS

    width:450px;
    height:450px;
    padding-top:50px;
}

By default, CSS uses content-box, so the actual height becomes:

450px + 50px padding = 500px

You can make the sizing easier to reason about with:

CSS
.container {
    box-sizing: border-box;
}

Then the 450px height includes the padding and border.

So your .container gets placed right in the middle of the page.
