README for Simple Weather API

Goal: Enable your user to enter a city + country and return the temperature in Fahrenheit

User is able to enter a location and get the temp of that area

API's Used
http://api.weatherapi.com/v1/forecast.json?key=${api_key}&q=${location}&days=1&aqi=no&alerts=no

- used to take the users location as a input and receive weather data based on its location. We then isolate an display the temperature of the area in Fahrenheit
